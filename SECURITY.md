# Security policy

## Supported versions

Only the [latest release](https://github.com/Skare69/velvarr/releases/latest) gets security fixes. Before you report a problem, update to the latest release and make sure that the problem still occurs.

## Report a vulnerability

Use private vulnerability reporting only:

1. Open the [Security tab](https://github.com/Skare69/velvarr/security) of this repository.
2. Select **Report a vulnerability**, or use [this link](https://github.com/Skare69/velvarr/security/advisories/new).
3. Write the affected version, the steps to reproduce the problem, and its effect.

Do not report a vulnerability in a public issue, a pull request, or a discussion.

## What to expect

- The maintainer reads the report and replies in the private advisory.
- The maintainer tells you if the report is accepted or declined, and why.
- When the report is accepted, the maintainer makes a fix and publishes it in a new release.
- After the release, the maintainer publishes the advisory. If you agree, the advisory gives you credit.

Velvarr is maintained by one person in free time. Thus, the project gives no fixed response time.
